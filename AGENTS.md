# AGENTS.md

## Repo Shape
- This repo is a single-file Node.js bot. `index.js` contains config, manual `.env` loading, AI/fallback text generation, README generation, git commit/push logic, and the cron entrypoint.
- Runtime state lives in `commit-log.json`. Generated output lives in `README.md`.

## Commands
- `npm install`: install the only dependency, `node-cron`.
- `npm start`: start the long-running cron scheduler.
- `npm run dev` or `node index.js --dev`: immediate real run. This updates `README.md` and `commit-log.json`, then runs `git add`, `git commit`, and `git push origin main`.
- Safe verification is limited to syntax checks like `node --check index.js`. There is no test, lint, formatter, or CI config in the repo.

## Behavior Gotchas
- `README.md` is generated by `updateReadme()` in `index.js`. Manual README edits will be overwritten on the next run unless you also change the template in code.
- Git auth for `git push` is not handled in code. The script assumes the machine already has working git credentials for `origin`.
- `GITHUB_TOKEN` is optional and is only used for GitHub Models text generation. If it is missing or the API fails, the bot falls back to local content collections.
- `.env` is loaded by the custom `loadEnv()` function in `index.js`; there is no `dotenv` dependency.
- The bot only stages `README.md` and `commit-log.json`. Auto-runs will not commit source changes.
- Generated content rotates in this fixed order based on `totalCommit`: `Puisi -> Pantun Jenaka -> Quote`.
- `commit-log.json` is pruned to the last 3 days on each run; older entries are removed automatically.

## Config Drift To Watch
- Executable source of truth for cadence, timezone, branch, and log retention is `CONFIG` in `index.js`.
- Human-readable schedule/rotation text is duplicated in `updateReadme()`, startup logs, and `SETUP.md`. If you change cadence, retention, content order, branch, or timezone, update those literals together.
